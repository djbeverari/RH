# Recursos Humanos (RH)

Recrutamento, desenvolvimento e gestão de pessoas na Dorinhos.

## Estrutura

- `CLAUDE.md` — Configuração de skills e preferências
- `MEMORY.md` — Índice de memória
- `memory/glossary.md` — Termos de RH, benefícios e processos

## Como Usar

Abra este projeto no Claude Code. Ele carregará automaticamente `CLAUDE.md` com as skills específicas para gestão de RH.

## Skills Disponíveis

- **product-management:brainstorm** — Brainstorm de iniciativas de RH
- **product-management:write-spec** — Definir processos de RH
- **product-management:roadmap-update** — Planejar roadmap de RH
- **customer-support:draft-response** — Rascunhar comunicações de RH
- **customer-support:kb-article** — Documentar políticas e procedimentos
- **data:analyze** — Análise de métricas de RH (turnover, satisfação, etc.)
- **productivity:task-management** — Rastrear recrutamento, onboarding, etc.

## Padrões

- Abordagem centrada em pessoas
- Documentação de processos
- Conformidade com legislação trabalhista brasileira (CLT)
